#+TITLE: LAR: Link Actors for Ripgrep
#+AUTHOR: Pierre-Henry FRÖHRING

* README
** Why
It would be useful if we could reference a piece of information in any text file just
by referencing an identifier, without being tied to a specific file format.

** What
LAR is an Emacs minor mode that defines locations and references across all files
under a configurable root directory.

** How
- *References*: ~[[ref:1234][some name]]~ or ~#+ref: 1234~.
- *Locations*: ~[[id:1234]]~ or ~:id: 1234~.

Clicking a link opens a ~grep-mode~ buffer listing all occurrences found by ~ripgrep~.

** Usage
*** Requirements
- [[https://github.com/BurntSushi/ripgrep][ripgrep]] (executable =rg=).
- Emacs version ≥ 29.1.
- [[https://github.com/jblevins/pcre2el][pcre2el]] (for regex conversion).

*** Installation
**** Via MELPA
~M-x package-install RET lar RET~

**** Manual
Clone the repository and add it to your load path:
#+begin_src emacs-lisp
(add-to-list 'load-path "/path/to/lar")
(require 'lar)
#+end_src

*** Get started
1. In =notes.org=, add: =[[id:42][The Answer]]=
2. In =todo.txt=, add: =[[ref:42][Check the answer]]=
3. Enable LAR mode: ~M-x lar-mode~.
4. Click the link to see occurrences.

*** Configuration
- =lar-root-directory=: Search base (default: ="~"=).
- =lar-rg-path=: Ripgrep path (default: ="rg"=).
