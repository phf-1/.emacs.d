* Integration
** lar-mode
M-x lar-mode is interpreted as emacs#lar-mode(). Clean all previously added overlays,
then add fresh overlays. On deactivation, remove all previously added overlays.

emacs#lar-mode() :≡
- root :≡ user defined path
- rg :≡ user defined path
- parser :≡ Parser#mk()
- searcher :≡ Searcher#mk(root rg)
- overlayer :≡ Overlayer#mk(searcher parser)
- buffer :≡ emacs#current-buffer()
- buffer :≡ overlayer#clean(buffer)
- links :≡ overlayer#links(buffer)
- ∀ link ∈ links, overlayer#add(buffer link)

** LinkString
A LinkString is a string that matches the following PEG grammar:
#+begin_example
LinkGrammar {
  link = globalLink | propertyLink | inlineLink
  globalLink = "#+" tag ":" space* id (space+ name)?
  propertyLink = ":" tag ":" space* id (space+ name)?
  inlineLink = "[" "[" tag ":" id "]" ("[" name? "]")? "]"
  id = alpha+
  name = alpha+
  tag = idTag | refTag
  idTag = "id" | "ID"
  refTag = "ref" | "REF"
  alpha = letter | digit | "_" | "-" | "."
}
#+end_example
