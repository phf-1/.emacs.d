A Link =link= is an abstract representation of a [[ref:33402f84-467c-4e42-89eb-6c75e31c8395][LinkString]]. If link#tag() =
loc, then link represents a position (link#start()) in the file link#path()
identified by link#id(). "identified by id" means that link#id() is synonymous to
<link#path(), link#start()>. If link#tag() = ref, then link represents a reference
from link#id() to a set of referenced locations locs :≡ { locLink : Link |
locLink#tag() = loc ∧ locLink#id() = link#id() }. If card(locs) = 0, then nothing
matches the reference.

*** Link#mk : Tag (id : Id) (start : Pos) (end : Pos) → Link

** LinkString
:PROPERTIES:
:ID:       33402f84-467c-4e42-89eb-6c75e31c8395
:END:

A LinkString is a string that matches the following PEG grammar:
#+begin_example
LinkGrammar {
  link = globalLink | propertyLink | inlineLink
  globalLink = "#+" tag ":" space* id (space+ name)?
  propertyLink = ":" tag ":" space* id (space+ name)?
  inlineLink = "[" "[" tag ":" id "]" ("[" name? "]")? "]"
  id = alpha+
  name = alpha+
  tag = locTag | refTag
  locTag = "id" | "ID"
  refTag = "ref" | "REF"
  alpha = letter | digit | "_" | "-" | "."
}
#+end_example
